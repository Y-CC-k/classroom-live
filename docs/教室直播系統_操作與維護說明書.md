# 教室直播系統_操作與維護說明書

**版本：** v0.1.0  
**適用平台：** Windows 10 / Windows 11  
**最後更新：** 2026-10-30

---

## 1. 系統總覽

### 1.1 功能總覽

教室直播系統（classroom-live）是專為教室教學設計的螢幕直播與課堂管理系統，包含以下角色：

| 角色       | 用途                                                | 安裝對象       |
| ---------- | --------------------------------------------------- | -------------- |
| 教師機     | 擷取螢幕廣播、監看學生、鎖定鍵鼠、送檔/升級、開關機 | 老師用電腦     |
| 學生機     | 接收廣播畫面、接受遠端控制、回傳監看畫面            | 學生用電腦     |
| 伺服器     | 信號轉發、房間管理、心跳偵測                        | 伺服器電腦     |
| 伺服器 GUI | 圖形化啟動/停止伺服器、查看線上統計                 | 資訊組管理電腦 |

### 1.2 系統架構

- **教師機 ↔ 學生機**：WebRTC P2P 直接連線，教師機為 Offerer。
- **信令伺服器**：僅轉發 WebRTC 信令（SDP/ICE），不處理媒體資料。
- **廣播模式**：支援視訊（WebRTC 即時）、圖片逐張（JPEG，低延遲適合多人教室）、SFU（選用）。
- **原生層**：Windows SendInput 鍵鼠注入，低階鉤子輸入攔截。

## 2. 安裝與部署

### 2.1 安裝包說明

| 安裝檔                                  | 用途                                               | 建議安裝對象                 |
| --------------------------------------- | -------------------------------------------------- | ---------------------------- |
| 教室直播 — 教師機 Setup 0.1.0.exe       | 教師機端程式                                       | 老師電腦                     |
| 教室直播 — 學生機 Setup 0.1.0.exe       | 學生機端程式（一鍵安裝＋登入自動啟動，無桌面圖示） | 學生用電腦                   |
| 教室直播 — 伺服機控制台 Setup 0.1.0.exe | 伺服器管理 GUI                                     | 伺服器管理電腦               |
| classroom-server.exe                    | 純信令伺服器（無 GUI）                             | 伺服器電腦（無需 GUI 時）    |
| 學生機升級包 0.1.0.zip                  | 學生機離線升級包                                   | 教師機透過「送檔／升級」傳送 |

### 2.2 安裝步驟

**學生機（一鍵安裝）：**

1. 將 `教室直播 — 學生機 Setup x.x.x.exe` 複製到學生電腦（可用網路芳鄰批次散佈）。
2. 執行安裝程式 → 自動安裝完成並**立即啟動**（不安裝桌面捷徑）。
3. **登入自動啟動已自動登記**：學生機開機後會隨 Windows 登入自動啟動並連線。
4. 開始選單保留「教室直播 — 學生機」捷徑，需要手動開啟時可從那裡啟動。
5. 設定（伺服器位址／班級代碼）可預先放在安裝目錄 `config.json` 隨包部署；或由學生機自動搜尋區網（見 4.2 節）。

**教師機（嚮導安裝）：**

1. 將 `教室直播 — 教師機 Setup x.x.x.exe` 複製到教師電腦。
2. 按照安裝嚮導完成安裝，桌面會出現捷徑。
3. 首次啟動時，設定伺服器位址與班級代碼。

### 2.3 伺服器部署

#### 方式 A：使用伺服器 GUI（圖形介面）

1. 安裝 `教室直播 — 伺服機控制台 Setup 0.1.0.exe`。
2. 啟動程式，點擊「啟動信號伺服器」。
3. 預設監聽 `0.0.0.0:8787`，可在設定中修改連接埠與上限人數。

#### 方式 B：直接執行純伺服器

1. 將 `classroom-server.exe` 複製到伺服器電腦。
2. 雙擊執行，即會在 `0.0.0.0:8787` 啟動。
3. 健康檢查：開啟瀏覽器輸入 `http://<伺服器IP>:8787/healthz`。

## 3. 教師機操作手冊

### 3.1 主畫面介紹

教師機主畫面分為三個區塊：

| 區塊                     | 說明                                                     |
| ------------------------ | -------------------------------------------------------- |
| **上方欄位**             | 伺服器位址、班級代碼、教師姓名、連線按鈕                 |
| **左欄（廣播來源）**     | 選擇擷取來源、畫質設定、開始/停止廣播                    |
| **中欄（學生清單）**     | 顯示已連線學生機、勾選框、狀態標籤                       |
| **右欄（單機功能）**     | 鎖定、解鎖、送檔、開網址、執行程式、關機、重開機、UWF 等 |
| **右下角（監看浮動窗）** | 單台學生機螢幕低頻回饋（每 3 秒一張）                    |

### 3.2 連線與班級

1. 輸入伺服器位址（例如 `ws://192.168.1.100:8787`）。
2. 輸入班級代碼（例如 `123-456`）。
3. 輸入教師姓名。
4. 點擊「連線」。
5. 等待學生機加入，學生清單會即時更新。

> **提示**：若資訊組已鎖定伺服器位址，位址欄位會鎖定不可修改。

### 3.3 廣播畫面

1. 在左欄選擇擷取來源：
   - **整個螢幕**：播放教師機整個桌面，遠端鍵鼠座標最精確（**建議**）。
   - **單一視窗**：只播放選定視窗，遠端鍵鼠座標可能對不準。
   - **攝影機**：播放攝影機或實物投影機畫面，無桌面內容。
2. 選擇畫質預設：
   - **每秒 2 張（截圖模式）**：負載最低，適合靜態簡報。
   - **講課簡報（5 fps）**：文字與簡報用，負載低。
   - **一般（10 fps）**：程式示範，負載與秒差平衡點（**預設**）。
   - **流暢（15 fps）**：影片或動態示範，負載較高。
   - **原始（30 fps）**：不縮放，秒差容易變大。
3. 點擊「開始廣播」。
4. 學生機畫面即會顯示教師機螢幕。

> **畫質調整建議**：學生機人數超過 15 台時，建議降至「講課簡報」或「每秒 2 張」，並開啟 H.264 硬體編碼，避免教師機編碼塞車導致畫面延遲越來越大。

### 3.4 課堂場景鍵

| 按鈕     | 功能                                             |
| -------- | ------------------------------------------------ |
| 教學活動 | 開始廣播、全班鎖定、全班靜音、學生機收攏到系統匣 |
| 學習操作 | 停止廣播、全班解鎖、全班取消靜音、學生機視窗隱藏 |

### 3.5 單機功能（勾選學生機後使用）

在學生清單中勾選一台或多台學生機後，中下方「單機功能列」會啟用：

| 按鈕      | 功能                     | 說明                             |
| --------- | ------------------------ | -------------------------------- |
| 🔒 鎖定   | 鎖定勾選學生機鍵盤滑鼠   | 學生畫面不動，但無法操作         |
| 🔓 解除   | 解除勾選學生機鎖定       | 學生恢復操作                     |
| 📁 送檔   | 送檔案給勾選學生機       | 檔案會落在學生機設定的收檔資料夾 |
| 🌐 開網址 | 要求勾選學生機開啟網址   | 學生機預設瀏覽器開啟             |
| ▶ 執行    | 執行學生機上已存在的檔案 | 學生機上必須已有該檔案           |
| ⏻ 關機    | 勾選學生機立即關機       | 需兩次確認                       |
| ⏻ 重開機  | 勾選學生機 10 秒後重開機 | 需兩次確認                       |
| ▶ 直播    | 只播勾選學生機           | 僅在圖片模式可用                 |

> 監看功能已由「🖥 監控牆」（3.8 節）取代，可同時監看全部學生機。

### 3.7 檔案傳送與升級

#### 3.7.1 送檔給學生機

1. 在「工作設定」區點擊「選擇檔案…」。
2. 選擇要傳送的檔案。
3. 點擊「送檔」，檔案會傳送給所有已連線學生機。
4. 若只想送給勾選的學生機，請在學生清單勾選後，點擊單機功能列的「送檔」。

#### 3.7.2 升級學生機程式

1. 準備好升級包 `.zip` 檔案（例如 `學生機升級包 0.1.0.zip`）。
2. 在教師機「工作設定」區點擊「選擇檔案…」，選擇升級包。
3. 點擊「送檔／升級」。
4. 教師端會自動偵測升級包並送給所有已連線學生機。
5. 學生機收到後會自動解壓覆蓋 `resources\app` 並重啟。
6. 教師端記錄會顯示各台升級結果。

> **注意**：
>
> - 升級包檔名建議包含「升級包」二字（例如 `學生機升級包 0.1.0.zip`）。
> - 升級包體積必須大於 32KB，否則會被判定為不可用。
> - 必須在 30 分鐘內收到，否則會被拒絕。

### 3.8 多螢幕監控牆

同時監看全部（或勾選的）學生機螢幕，取代舊版單台監看。

**操作：**

1. 點擊頂部工具列「🖥 監控牆」。
2. **有勾選學生機** → 只監看勾選的台；**沒有勾選** → 監看全部已連線學生機。
3. 全螢幕網格顯示各台畫面（每 5 秒一張 JPEG，29 台約僅佔 1.5 Mbps）。
4. 每格顯示學生機名稱、畫面、幀序號；**超過 20 秒沒收到畫面的格子標示「訊號中斷」**。
5. 再點一次按鈕關閉，全部監看自動停止。

**注意：**

- 控制通道未連線的學生機會自動排除（不會出現空格子）。
- 開啟電子白板時會自動關閉監控牆以釋放頻寬，結束白板後可重新開啟。

### 3.9 電子白板

全螢幕白底書寫，筆跡即時同步到所有學生機（蓋過廣播畫面）。

**操作：**

1. 點擊頂部工具列「📝 電子白板」（**只要已連線即可用**，不需要開始廣播）。
2. 教師機進入全螢幕白紙，學生機同步變成白板。
3. 工具列（畫面下方）：
   - 色點：黑／紅／藍／綠／橙
   - ✏ 畫筆 / 🧽 橡皮擦 切換
   - 粗細：細／中／粗
   - ↺ 復原上一筆、🗑 清除全部（同步全班）
4. 按「✕ 結束白板」→ 學生機恢復原畫面。

**注意：**

- 白板開啟期間「停止」廣播按鈕會鎖住（離開白板後恢復）。
- 白板中按「斷線」會先自動收白板再斷線。
- 廣播中也可用「疊加標註」嗎？目前標註功能已整合進電子白板。

---

### 3.10 更換學生機待機畫面

學生機開機後、尚未接收廣播時顯示的「待機畫面」，可由教師機遠端更換文字與底圖。

**更換文字：**

1. 右欄「學生機待機畫面」區塊輸入標題（如「第三節 資訊課」）與內容（如「請靜候廣播」）。
2. 按「更新」→ 全部已連線學生機立即顯示並永久保存（下次開機也顯示）。
3. 兩個欄位都清空再按「更新」→ 恢復系統預設。

**更換底圖：**

1. 按「🖼 更換待機圖…」選擇圖片（PNG/JPG/WebP）。
2. 圖片會傳送到各台學生機（取代內建的電腦教室使用守則海報），落地後自動套用。
3. 待機圖同時會留在學生機的收檔資料夾一份。

## 4. 學生機操作手冊

### 4.1 主畫面介紹

學生機主要畫面為「待機」狀態，顯示待機底圖與狀態列（「已連線，等待教師廣播…」）。

待機底圖預設為內建的電腦教室使用守則海報；**教師機可遠端更換文字與底圖**（見 3.10 節），更換後每次開機都會顯示自訂內容。

當教師開始廣播時，學生機畫面會自動顯示教師廣播畫面，並自動切換到全螢幕模式（若啟用自動全螢幕）。教師開啟電子白板時，學生機會切換為全螢幕白板。

### 4.2 連線設定

1. 啟動學生機程式。
2. 伺服器位址與班級代碼通常由資訊組預先設定，若未鎖定可自行修改。
3. 點擊「連線」。
4. 成功連線後，橫幅顯示「已連線，等待教師廣播…」。
5. 學生機名稱固定為本機 IP（例如 `172.16.100.33`），老師清單上可直接對應；偵測不到 IP 時改以電腦名稱顯示。

#### 連不上伺服器？自動搜尋區網

連線嘗試約 10 秒仍未成功時，學生機會**自動以 UDP 廣播搜尋區網中的教室伺服器**：

- 搜尋到伺服器時，畫面列出找到的位址，點選「✓ 使用 ws://x.x.x.x:8787（儲存並連線）」即會**儲存該位址並重新連線**。
- 也可在設定面板手動按「🔍 搜尋區網伺服器」。
- 搜尋不到時請確認教師機／伺服器已啟動，且與學生機在同一網段。

### 4.3 視窗內選單（☰）

學生機視窗右下角有一個 ☰ 選單，包含：

| 選單項目   | 行為                                           |
| ---------- | ---------------------------------------------- |
| 顯示視窗   | 若視窗已隱藏，將其拉回前景                     |
| 切換全螢幕 | 切換全螢幕／視窗模式                           |
| 重新連線   | 離線後重新連線到班級                           |
| 設定       | 打開設定抽屜（修改伺服器、班級、收檔資料夾等） |
| 縮到系統匣 | 隱藏視窗，程式留在背景繼續上課                 |
| 結束學生機 | 結束程式                                       |

> **注意**：學生機常駐於系統匣，關閉視窗不會結束程式，老師仍可找到該台機器。如需完全結束，請使用系統匣選單的「結束」。

### 4.4 緊急解鎖

若學生機被教師鎖定鍵盤滑鼠，學生可按下：

> **Ctrl + Alt + Shift + Esc**

立即解除本機鍵盤滑鼠鎖定，並回報教師端。此熱鍵無法被停用，是學生自救出口。

## 6. 開機還原（UWF）遙控

開機還原（Unified Write Filter，UWF）可讓學生機重開機後自動還原至初始狀態，適合電腦教室環境。

### 6.1 支援動作

| 動作          | 說明                                        |
| ------------- | ------------------------------------------- |
| 初始化還原    | 初始化排程任務（每台機器需跳一次 UAC 確認） |
| 安裝/重設 UWF | 安裝開機還原功能（需重開機生效）            |
| 查狀態        | 查詢還原開關與疊層用量                      |
| 維護 開       | 暫停開機還原（裝軟體時用）                  |
| 維護 關       | 恢復開機還原                                |
| 完全移除      | 完全移除 UWF（需兩次重開機）                |
| 加入排除區    | 指定資料夾不受開機還原影響（重開後保留）    |

### 6.2 操作流程

1. 教師機選擇學生機（一台或多台）。
2. 在右欄「開機還原設定」區選擇動作。
3. 若是「初始化」，學生機螢幕會跳出 UAC 視窗，需現場按「是」。
4. 結果會回報到教師機記錄區。

> **注意**：安裝/移除/維護開關變更後，需重開機學生機才生效。請搭配「重開機全班」按鈕使用。

## 7. 一鍵開機（Wake-on-LAN）

教師機可從名單中喚醒關機的學生機。

### 7.1 前置條件

1. 學生機主機板與網卡必須支援 Wake-on-LAN。
2. BIOS 中必須啟用 Wake-on-LAN。
3. 教師機與學生機必須在同一區網。

### 7.2 操作

1. 學生機至少連線過一次，MAC 位址會自動記錄到教師機喚醒名單。
2. 教師機點擊「一鍵開機」。
3. 系統會發送 Magic Packet 給該學生機，電腦會自動開機。
4. 學生機開機後若設定了「登入自動啟動」，程式會自動啟動並連線到班級。

## 8. 常見問題（FAQ）

| 問題                            | 可能原因                                 | 處理方式                                                        |
| ------------------------------- | ---------------------------------------- | --------------------------------------------------------------- |
| 學生機連不上伺服器              | 伺服器 IP 錯誤、防火牆封鎖 8787 連接埠   | 確認伺服器 IP 正確，開啟防火牆 8787 連接埠                      |
| 廣播畫面卡頓或延遲變大          | 編碼負載過高、學生機人數過多             | 降低畫質預設（例如 5 fps 或 2 張/秒），開啟 H.264 硬體編碼      |
| 遠端控制沒反應                  | 學生機未以系統管理員執行、原生模組未編譯 | 以系統管理員身分執行學生機，確認原生模組已編譯                  |
| 學生機顯示 `nativeReady: false` | 原生模組未編譯或 ABI 不符                | 執行 `npm.cmd run build:native` 及 `npm.cmd run rebuild:native` |
| 升級包沒自動套用                | 檔案大小小於 32KB、或超過 30 分鐘未傳送  | 確認升級包大小大於 32KB，且在 30 分鐘內送出                     |
| 學生機找不到托盤圖示            | Windows 11 預設收起新圖示                | 使用學生機視窗右下角的 ☰ 選單                                  |
| 電子白板寫不出字                | 廣播連線的 ctl 通道未連上                | 確認學生機已連線；離開白板再重新進入                            |
| 電子白板開啟後學生機停在白板    | 白板中斷線導致收不到「結束」指令         | 學生機斷線重連即恢復；教師端斷線會自動先收白板                  |
| 監控牆格子顯示「訊號中斷」      | 該台學生機離線或網路逾時                 | 確認該台連線；恢復後 5 秒內畫面會回來                           |
| 學生機連不上設定的伺服器        | 伺服器位址錯誤或換教室                   | 學生機 10 秒後自動搜尋區網，點選找到的位址即可儲存連線          |
| 學生機名稱顯示 127.0.0.1        | 該機器偵測不到區網 IPv4                  | 已改為顯示電腦名稱；請更新學生機至最新版                        |

## 9. Git 版本控制與 GitHub 操作

本章節說明如何將本專案原始碼納入 Git 版本控制，並推送到 GitHub 遠端倉庫，方便團隊協作與版本追蹤。

### 9.1 安裝 Git

請從 [Git 官方網站](https://git-scm.com/download/win) 下載並安裝 Git for Windows。

安裝時關鍵選項：

- **PATH**：選擇 `Git from the command line and also from 3rd-party software`
- **HTTPS transport**：選擇 `Use the OpenSSL library`
- **Line endings**：選擇 `Checkout Windows-style, commit Unix-style line endings`

安裝完成後，**請重新開啟 PowerShell**，並在終端機驗證：

```powershell
git --version
```

### 9.2 初始化本地 Git 儲存庫

在專案根目錄執行：

```powershell
cd D:\classroom-live
git init
```

### 9.3 設定 Git 使用者資訊（只需設定一次）

```powershell
git config --global user.name "你的名字"
git config --global user.email "你的 email@example.com"
```

### 9.4 建立 .gitignore（排除大檔案）

為了避免 Electron 打包後的 `.exe` 安裝程式超過 GitHub 100 MB 限制，必須建立 `.gitignore` 排除建置輸出與大檔案：

```powershell
@"
# Electron 打包輸出（大檔案，不納入版本控制）
dist-electron/

# Node 模組
node_modules/

# 建置輸出
packages/*/dist/
packages/*/build/

# 日誌
*.log
*.zip

# IDE
.vscode/
.idea/

# OS
.DS_Store
Thumbs.db
"@ | Out-File -Encoding utf8 .gitignore
```

### 9.5 加入檔案並 Commit

```powershell
git add -A
git commit -m "feat: initial commit - classroom-live project"
```

### 9.6 在 GitHub 上建立遠端倉庫

1. 開啟 [GitHub](https://github.com) 並登入帳號
2. 點擊右上角 `+` → **New repository**
3. Repository name 填寫：`classroom-live`
4. 選擇 **Private** 或 **Public**
5. **不要勾選** "Add a README file"（避免與本地檔案衝突）
6. 點擊 **Create repository**
7. 記下遠端網址，例如：`https://github.com/Y-CC-k/classroom-live.git`

### 9.7 連接遠端並推送

將 `Y-CC-k` 替換為你的 GitHub 帳號：

```powershell
git remote add origin https://github.com/Y-CC-k/classroom-live.git
git branch -M main
git push -u origin main
```

推送成功後，即可在瀏覽器查看：

```
https://github.com/Y-CC-k/classroom-live
```

### 9.8 常見問題

#### 問題：推送失敗，大檔案超過 100 MB

若 `.exe` 安裝程式已誤加入 Git 追蹤，需從歷史中移除：

```powershell
git rm -r --cached dist-electron/
git rm -r --cached packages/*/dist/
git rm -r --cached packages/*/build/
git add -A
git commit -m "fix: exclude large Electron installer binaries"
git push -u origin main
```

> Electron 安裝程式 `.exe` 建議透過 **GitHub Releases** 分發，不適合直接放在 Git 儲存庫。

#### 問題：推送時要求輸入密碼

GitHub 已停止支援直接使用密碼，請使用 **Personal Access Token (PAT)**：

1. GitHub Settings → Developer settings → Personal access tokens → Tokens (classic)
2. 生成新 Token，勾選 `repo` 權限
3. 推送時在密碼欄位貼上 Token

### 9.9 後續維護指令

| 用途         | 指令                                               |
| ------------ | -------------------------------------------------- |
| 查看提交歷史 | `git log --oneline`                                |
| 查看目前狀態 | `git status`                                       |
| 查看修改內容 | `git diff`                                         |
| 後續變更提交 | `git add -A` → `git commit -m "訊息"` → `git push` |
| 從遠端拉取   | `git pull`                                         |

## 10. 法律與倫理注意事項

遠端控制他人電腦是**高風險能力**，誤用可能觸法。請務必遵守以下原則：

1. **取得明確同意**：學生及其法定代理人（若未成年）必須事前告知並同意裝置可能被遠端檢視與控制。
2. **保留緊急解鎖**：`Ctrl + Alt + Shift + Esc` 不可被停用，且解除行為應能即時通知使用者。
3. **僅在受控環境使用**：限於自有或已受管理的教學裝置，不可安裝在他人未授權的機器上。
4. **遵守當地法規**：可能涉及刑法妨害電腦使用罪、個人資料保護法等，請諮詢法務。
5. **資料最小化**：畫面與輸入事件屬敏感資料，請勿錄存或外流。
